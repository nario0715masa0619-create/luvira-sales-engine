# ADR-0002: API-Independent MVP

## Status

Accepted.

## Decision

The MVP uses permitted public, API-independent sources and manual seed lists.
It does not assume access to NTA Web-API or gBizINFO API.

## Rationale

External approvals are pending, while the purpose of this MVP is timely revenue
validation. NTA Corporate Number CSV may be evaluated when available without an
API and permitted for the intended use.
