# Data Source Policy

## Rule

**Decision:** "It can be scraped" is never sufficient justification. Evaluate
legality, terms of use, commercial reuse, storage permission, reliability,
provenance quality, acquisition effort, and automation difficulty before use.

## Preferred initial sources

**Decision:** Prefer industry associations, cooperatives, chambers of commerce,
local-government directories, permit/license lists, NTA Corporate Number CSV if
available without an API, public web search, manual seed lists, and referrals.
Research official websites only after the company is discovered.

## Restricted sources

**Decision:** Google Maps/Business Profile, recruitment sites, commercial list
providers, scraped portals, and SNS require source-specific terms and use review.
Google Maps is not a primary persistent commercial outreach database unless its
terms or an approved API allow the intended use.

## Recordkeeping

**Decision:** Store source URL/reference, access date, permitted-use assessment,
captured facts, and reviewer note for every candidate source.
