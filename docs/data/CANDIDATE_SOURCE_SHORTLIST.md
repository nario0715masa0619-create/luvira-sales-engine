# Candidate Source Shortlist

## Approved for MVP, subject to source terms

**Decision:** Start with industry-association member lists, cooperatives,
chamber-of-commerce public member lists, local-government public business
directories, public construction permit/license lists, manual seed lists, and
referrals or known local businesses. NTA Corporate Number CSV is optional only
when available without an API and its terms permit the intended use.

## Careful: manual review before use

**Decision:** Recruitment sites, SNS profiles, Google Business Profile,
commercial directories, and portal sites require recorded terms, commercial-use,
storage, and provenance review. They are not default discovery sources.

## Prohibited unless separately approved

**Decision:** Do not use Google Maps scraping; sources prohibiting commercial
use, storage, or reuse; sources requiring login with unclear terms; purchased
lists without provenance; or any source with unknown legality or terms.

## Source record

For each source, record name, URL/reference, type, access date, terms checked,
intended-use decision, and reviewer note. Discover company names from these
non-website sources first; public search is verification after discovery.
