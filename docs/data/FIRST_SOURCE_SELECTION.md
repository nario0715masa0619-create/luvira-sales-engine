# First Source Selection

**Decision:** This document approves a selection process, not any specific
source. No source may supply first-100 candidates until it is `Approved For
Manual Collection`.

## Preference order

1. Public industry-association or cooperative member lists for electrical,
   HVAC, plumbing, pipework, equipment work, or specialist construction.
2. Local-government or public permit/license lists.
3. Chamber-of-commerce public member directories.
4. Manual seed lists or known local businesses.
5. Public web search only to verify website status after discovery.

## Region order

**Hypothesis:** Start with Hyogo, then Osaka and Kyoto. If the reviewed supply
is insufficient, evaluate Nara, Shiga, Wakayama, then Okayama.

## Approval checklist

Record source name, URL, type, region, subsegment, public-access status, terms
check, apparent commercial-use/storage/reuse allowance or prohibition, login
requirement, robots/terms collection restriction, candidate density, provenance
quality, approval status, reviewer, and notes.

## Approval status

| Value | Meaning |
| --- | --- |
| Proposed | Candidate source not yet reviewed |
| Terms Review Needed | Intended-use terms are unresolved |
| Approved For Manual Collection | A reviewer approved manual candidate capture |
| Rejected | Not suitable or use is prohibited |
| Needs Legal / Human Decision | Material uncertainty requires an explicit decision |

## Exclusions

**Decision:** Do not use Google Maps scraping, unclear commercial-use sources,
login-only sources with unclear terms, sources prohibiting storage/reuse or
commercial use, purchased lists without provenance, or automated extraction
from sites not explicitly approved for automation.

See [Candidate Source Shortlist](CANDIDATE_SOURCE_SHORTLIST.md) for source
categories and provenance rules.
