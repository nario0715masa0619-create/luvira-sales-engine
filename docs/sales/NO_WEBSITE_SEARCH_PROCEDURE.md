# No Website Search Procedure

**Decision:** This procedure verifies web presence only after a company name is
discovered from an approved non-website source. Never use an official company
website as the primary way to find a No Website Candidate.

## Minimum documented search

1. Search company name plus location.
2. Search company name plus business category.
3. If available, search company name plus phone number.
4. If available, search company name plus representative name.
5. Record queries, date, URLs reviewed, and conclusion.

## Classify the result

- **No Website Candidate:** no official site found after the documented search.
  This is an observed conclusion, never proof that no site exists.
- **Weak Website Candidate:** official site found, with one or more specific
  observable weakness signals recorded.
- **Has Adequate Website:** official site found without a relevant clear
  weakness; normally not a target for this experiment.
- **Not Enough Evidence:** search results cannot support a reliable conclusion.
- **Needs Human Review:** identity, ownership, evidence, or suitability remains
  unresolved.

## Page-type distinction

**Decision:** A domain or page is official only when ownership is plausible from
the page and matching public identity evidence. Portal listings, SNS profiles,
Google Business Profile, directories, and recruitment pages are third-party
presence, not official websites by default. Record them as evidence; do not
mistake them for proof of an official website or of its absence.
