# Website Status Taxonomy

| Status | Definition |
| --- | --- |
| No Website Candidate | No official website found after documented public search; not proof that none exists |
| Weak Website Candidate | Official site exists with documented, obvious weakness signals |
| Not Target | Official web presence or context does not fit this experiment |
| Needs Human Review | Identity, website ownership, evidence, or suitability is unresolved |

**Decision:** Search results alone are not proof of company identity. Record
queries, dates, URLs, and the reviewer conclusion. Examples of observable
weakness: broken primary navigation, no usable inquiry route, clearly obsolete
content, or a mobile-unusable primary page. Do not use subjective aesthetics as
the only signal.
