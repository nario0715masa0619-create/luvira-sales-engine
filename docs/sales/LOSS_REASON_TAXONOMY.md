# Loss Reason Taxonomy

**Decision:** Use one primary loss reason, with a short factual note where needed.

| Value | Meaning |
| --- | --- |
| No Response | No response within the experiment's defined follow-up window |
| Not Interested | Company declined interest |
| Already Has Vendor | Existing provider satisfies the need |
| No Budget | Budget unavailable |
| Too Expensive | Price was the stated barrier |
| Timing Not Right | Interest deferred due to timing |
| Contact Prohibited | Contact route or company policy prohibited it |
| Bad Fit | Offer or segment did not fit |
| Wrong Contact | Contact did not reach an appropriate person |
| Duplicate | Duplicate company or sales record |
| Other | Explain in notes |

**Decision:** Record only stated or observed reasons. Do not infer motivation
from silence; use `No Response` only after the first experiment's follow-up
window has passed.
